## 1. 项目概述

链上财务系统已完成统一化建设，核心目标为：

- 将**链上监听**与**企业财务记账**整合为同一入口
- 打通「监听 → 入账 → 对账 → 报表 → 审计」完整链路
- 支持本地环境快速启动与端到端验证

当前状态：**功能完成，可启动使用**。

---

## 2. 功能架构（统一入口）

系统入口：`链上财务`

包含 4 个核心功能模块：

1. **链上监听**
   - 监听地址管理（增删改）
   - 监听统计（数量、入出金、盈亏）

2. **对账工作台**
   - 待对账流水列表
   - 会计科目选择与确认对账

3. **财务报表**
   - 按月份生成报表
   - 支持 PDF / Excel

4. **审计日志**
   - 操作留痕
   - 支持按条件筛选

数据流：

`链上交易 -> address_monitors -> finance_ledgers -> reconcile -> audit_logs -> reports`

## 4. 数据库设计

核心表（4个）：

- `address_monitors`：监听配置与状态
- `finance_ledgers`：财务流水主账
- `chart_of_accounts`：会计科目（已初始化 13 个）
- `audit_logs`：审计日志

## 5. API 清单（v1）

### 监听管理

- `GET /api/v1/monitors/finance/monitors`
- `POST /api/v1/monitors/finance/monitors`
- `DELETE /api/v1/monitors/finance/monitors/{id}`
- `PATCH /api/v1/monitors/finance/monitors/{id}`

### 交易与对账

- `GET /api/v1/monitors/finance/transactions`
- `GET /api/v1/monitors/finance/summary`
- `POST /api/v1/monitors/finance/reconcile`

### 科目/日志/报表

- `GET /api/v1/monitors/finance/account_categories`
- `GET /api/v1/monitors/finance/audit_logs`
- `GET /api/v1/monitors/finance/reports/generate`
